# Specsy Online
 
Streamlit wrapper for [Specsy](https://github.com/Vital-Fernandez/specsy) — a Python library for astrophysical spectral analysis.
 
## Installation
 
```bash
pip install specsy-online
```
 
## Usage
 
Launch the Streamlit app from the terminal:
 
```bash
specsy-online
```
 
## Dependencies
 
This package relies on the following libraries:
 
- [Specsy](https://github.com/Vital-Fernandez/specsy) — spectral analysis core
- [Lime](https://github.com/Vital-Fernandez/lime) — line measuring engine
- [Aspect](https://github.com/Vital-Fernandez/aspect) — plotting utilities
- [Innate](https://github.com/Vital-Fernandez/innate) — supporting tools
- [PyNeb](https://pypi.org/project/PyNeb/) — nebular emission line analysis
- [Streamlit](https://streamlit.io/) — web app framework
